# Komax Review Sandbox Data

Place exported or mock Komax Coupang review data here.

Suggested file shapes:

- `products.json` for product-level rating, review count, URL, and category data
- `reviews.jsonl` for individual review rows
- `snapshots/YYYY-MM-DD.json` for dated product snapshots

The current automation can produce a report even when this folder only has placeholder data. Add exports here as the data collection layer matures.
